# 🎾 Tennisschule Amir – Modern Relaunch Demo

Ein moderner Webauftritt für die **Tennisschule Amir** ([ts-amir.de](https://ts-amir.de/)) mit klarer, athletischer Informationsarchitektur.

---

## 🌟 Highlights & Features

- **Cheftrainer-Profil Amir Reza**: Ehemaliger Davis-Cup-Spieler, ATP Weltranglistenprofi, höchstzertifizierter **GPTCA / ATP A-Level Coach** und offizieller **Talent Scout der Rafa Nadal Academy**.
- **Offizieller Partner SG Weiterstadt**: Komplette Übernahme des Trainingsbetriebs ab Wintersaison 2025/2026/2027.
- **3-Säulen-Trainingssystem**:
  1. *Gruppentraining & Heidelberger Ballschule* (max. 4 Spieler pro Platz, ab 5 Spieler 2 Trainer).
  2. *Privat- & Einzeltraining* (10er-Karte mit individueller Video- & Biomechanik-Analyse).
  3. *Feriencamps & Clinics* (Oster- & Sommercamps mit über 100 Teilnehmern jährlich).
- **Interaktive Preismatrix**: Transparente Saisonkalkulation (Winter 2026/27 inkl. Hallenplatzgebühr vs. Sommer 2026).
- **Turnier-Erfolge (Hall of Fame)**: Echte Nachwuchsmeisterschaften (Patrice Flügge, David Medic, Stella Schweizer, Sam Pazoki) und Kundenbewertungen.
- **Interaktives Buchungs- & Schnuppermodal**: Direktes Anfrageformular mit Spielstärkeneinstufung.
- **Sportliche Typografie**: Lokale Bereitstellung von *Montserrat* (Headlines) & *Plus Jakarta Sans* (Fließtext) – 100% DSGVO-konform ohne externe CDN-Aufrufe.

---

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router, Static Export)
- **Sprache**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS & Glassmorphic Design-Tokens
- **Animationen**: Framer Motion
- **Icons**: Lucide React
- **Hosting**: GitHub Pages (automatisiert via GitHub Actions) / Vercel-ready

---

## 🚀 Lokale Entwicklung

```bash
# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev

# Produktions-Build testen
npm run build
npm start
```
Die Anwendung ist anschließend unter `http://localhost:3000` erreichbar.
